Flex settings

Choose which Flex times parents can pick on the Tuition & Plans page. Open a few at launch, then open more as sections fill. Standard times are always open.

How to publish a change

  1. Tick the Flex times to open for each subject, for each level and market.
  2. Press Download flex-settings.json.
  3. In your GitHub repository, upload that file next to tuition-plans.html, replacing the old one. The Tuition & Plans page uses it within a minute or two.

This page never changes the live site by itself. If flex-settings.json is missing, every Flex time shows. A subject with none ticked also shows every time, so a parent is never left without a choice.
