SAP BASIS · AWS · ECC 6.0 EHP8 · MSSQL

AWS-hosted SAP ECC 6.0 EHP8 QAS Lab — Installation & System Build

Project

Designed and built a hands-on SAP ECC 6.0 EHP8 environment hosted on AWS, using Microsoft Windows Server 2019 and Microsoft SQL Server 2017. The work covered the infrastructure preparation, database installation, SAP media preparation and SAP installation through Software Provisioning Manager (SWPM).

Sizing & preparation

Worked through SAP Quick Sizer concepts using user-based and throughput-based sizing, then prepared the operating-system and storage requirements. The installation checklist covered the ECC Master Guide, S-User/media requirements, SAP kernel, SWPM, SAP Host Agent and database media.

Database layer

Installed Microsoft SQL Server 2017 Developer Edition, configured the SQL Server instance and applied the SAP-relevant collation SQL_Latin1_General_CP850_BIN2. The environment used Windows authentication and was prepared as the database layer for the ECC installation.

SAP installation

Executed sapinst.exe through SWPM as administrator, selected SAP Business Suite / ERP 6.0 EHP8 (ABAP), configured the SID and master credentials, supplied the SAP kernel and export media, reviewed database/data-file parameters, configured parallel export jobs and completed the installation while monitoring the installation logs.

Instance configuration

The documented lab used distinct instance numbers for the SAP ECC system, including PAS 55 and ASCS 51, while keeping instance-number uniqueness in mind when multiple SAP systems share infrastructure.

Validation & operational understanding

Validated the completed installation through the SAP Management Console and documented how PAS, ASCS and the database instance work together. The documentation also covers standard versus distributed installation models, resource isolation, unique SIDs/instance numbers and considerations for running multiple test systems on one host.

Outcome

A successfully installed SAP ERP ECC 6.0 ABAP environment and a reusable Basis installation runbook covering sizing, Windows preparation, SQL Server, SWPM parameters, instance configuration and post-installation validation.
